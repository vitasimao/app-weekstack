# ⚡ WeekStack — Micro-Planner Semanal / Weekly Task App

**WeekStack** es una aplicación web minimalista de productividad semanal diseñada para eliminar la sobrecarga cognitiva. Ofrece una experiencia fluida, reactiva y sin fricciones para gestionar tareas diarias con persistencia local y soporte para recurrencia inteligente.

*WeekStack is a minimalist weekly productivity web app engineered to eliminate cognitive overload. Built with a fast, zero-friction interface, it provides smooth daily task tracking with local data persistence and smart recurring logic.*

👉 **[Ver Demo en Vivo / Live Demo](https://vitasimao.github.io/app-weekstack/)**

---

### 🚀 Características / Key Features

* 🗓️ **Gestión Semanal / Weekly Layout:** Vista interactiva de 7 días organizada en tarjetas desplegables para mantener el enfoque diario. *(7-day interactive view grouped into collapsible cards for streamlined focus).*
* 🔁 **Recurrencia Inteligente / Smart Recurring Engine:** Programación flexible de tareas diarias, semanales o por días laborables (L-V). *(Flexible task scheduling for daily, weekly, or workday cycles).*
* ✂️ **Eliminación Granular / Exception Logic:** Permite omitir ocurrencias individuales (`Solo esta ocurrencia`) mediante un sistema de excepciones (`excludedDates`) sin alterar ni destruir la serie original. *(Delete single instances using an exception tracking system without modifying the main series).*
* 🧹 **Auto-Limpieza / Auto-Clean:** Opción configurable en ajustes para ocultar automáticamente las tareas completadas. *(Toggle option in settings to automatically hide completed tasks).*
* 🌙 **Modo Oscuro Adaptativo / Dark Mode:** Sincronización completa con las preferencias del sistema y selector manual. *(Full dark/light UI mode synchronization).*
* 💾 **Persistencia Local / Local Data:** Integración directa con `LocalStorage API` para un funcionamiento instantáneo y 100% offline. *(Powered by LocalStorage API for offline capability).*
